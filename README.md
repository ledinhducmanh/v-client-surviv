# 🚀 Installation & Usage Guide

This guide provides step-by-step instructions on how to install and run the script using the Tampermonkey extension on Google Chrome.

## 📋 Prerequisites
*   **Google Chrome** browser installed.
*   The script file: `deobfuscated.js`.

---

## 🛠️ Step-by-Step Instructions

### Step 1: Install Tampermonkey
1. Open the **Chrome Web Store**.
2. Search for and select the official **[Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)** extension.
3. Click **Add to Chrome** to install it.
<img width="503" height="257" alt="image" src="https://github.com/user-attachments/assets/1babe2dc-06e4-4de3-838c-161350f278a2" />

### Step 2: Create a New Script
1. Click the **Tampermonkey** icon on your Chrome toolbar.
2. Select **Create a new script...**.
3. A code editor window will appear.
<img width="665" height="166" alt="image" src="https://github.com/user-attachments/assets/e17c5e89-ca1e-4fd6-b2a3-2e9c537bdb7f" />

### Step 3: Paste the Code
1. Open the `deobfuscated.js` file using **Notepad** (or any text editor).
2. Press `Ctrl + A` to select all, then `Ctrl + C` to copy.
3. Go back to the Tampermonkey editor:
    *   Press `Ctrl + A` to select the default template code.
    *   Press `Ctrl + V` to paste your copied code.
4. Press `Ctrl + S` to save the script.
<img width="1395" height="892" alt="image" src="https://github.com/user-attachments/assets/e98b4a43-42f6-449b-bfed-576549c72cf7" />


### Step 4: Launch & Test
1. Navigate to: **[surviv.io](https://surviv.io/)**.
2. Refresh the page using `Ctrl + F5`.
3. Verify that the script is running correctly.
